# Legal Pages Pattern

All three legal pages (PrivacyPolicy, Terms, RefundPolicy) follow this consistent structure:

1. **Back nav** — `← Back to Home` arrow link at top using `Link` from wouter + ArrowLeft icon
2. **Card header** — `bg-card border border-white/10 rounded-2xl p-6` with icon in colored circle + title + subtitle meta line
3. **Prose content** — existing section content unchanged
4. **Bottom CTA card** — `mt-12 bg-card border border-white/10 rounded-2xl p-6` with description text + 2 action buttons (Contact Us as primary yellow, secondary action as ghost)

**Why:** Consistency across legal pages; users landing from footer links need navigation context and an action path after reading.

**How to apply:** Any new legal/policy page should follow this same 4-part structure. Icon color choices: Shield=primary/yellow for Privacy, Scale=primary/yellow for Terms, RotateCcw=green for Refund.
